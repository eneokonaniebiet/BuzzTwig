# API v1

Base path: /v1

Auth:
- POST /auth/register
- POST /auth/login
- POST /auth/refresh
- POST /auth/logout

Users:
- GET /users/me
- PATCH /users/me

Messaging:
- GET /rooms
- POST /rooms
- GET /messages/:roomId
- POST /messages/:roomId

Communities:
- GET /communities
- POST /communities
- POST /communities/:id/join

Notifications:
- GET /notifications
- POST /notifications/:id/read

Wallet:
- GET /wallet/me
- GET /wallet/ledger

All authenticated endpoints require a verified Bearer access token.
